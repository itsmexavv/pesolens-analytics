# Presenting PesoLens

## Suggested portfolio entry

**PesoLens — Expense analytics.** A standalone Python and JavaScript project with an interactive interface, persistent SQLite data, validated API inputs, automated tests, and a reproducible Codespaces setup.

Adapt this description to your actual understanding and contributions. The starter was built with AI assistance; do not claim that you independently authored every component.

## Three-minute walkthrough

1. Explain the problem in README.md and show the normal workflow.
2. Trigger one invalid input and explain why it is rejected.
3. Open app.py and trace the central design decision.
4. Run `python -m unittest discover -v` and explain one meaningful test.
5. Discuss one current limitation and your next change.

## Questions to prepare for

- Why is validation also performed in Python when the browser validates forms?
- What does your central data model or syntax tree represent?
- How does the project preserve consistency when a request fails?
- What would change for multiple users or a public deployment?
- Which test caught a real risk, and what behavior does it verify?

## Make a contribution you can explain

Choose one extension from README.md. Write the expected behavior, implement it, add a test for a meaningful failure case, and record the before/after behavior in your own commit. Add your own screenshot and a short explanation of what you learned.
